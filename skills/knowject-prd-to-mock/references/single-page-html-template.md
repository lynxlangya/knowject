# Single-page HTML template

The mock is one `.html` file that opens directly in a browser. No build, no bundler, no server.

## Skeleton

```html
<!doctype html>
<html lang="<locale>">
<head>
  <meta charset="utf-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1" />
  <title><project_name> · <page-slug></title>
  <script src="https://cdn.tailwindcss.com"></script>
  <link href="https://fonts.googleapis.com/css2?family=<url-encoded font_family primary>&display=swap" rel="stylesheet" />
  <!-- CSS variable shim from references/brand-token-mapping.md -->
</head>
<body class="bg-slate-50 text-slate-900 min-h-screen">
  <!-- header / main / aside / footer per PRD -->
</body>
</html>
```

## Hard rules

1. **Self-contained.** Only allowed external loads: Tailwind CDN, Google Fonts CSS, the project's own `logo_path` (if set). Do not load any other JS, no analytics, no inline scripts, no external CSS frameworks.
2. **No build step.** No `import`, no `<script type="module">`, no JSX. If interactivity is part of the PRD, mock it visually (hover states via Tailwind) and add one-line comment `<!-- TODO: <interaction> wired up by frontend implementation -->`.
3. **Width default desktop.** `max-w-7xl mx-auto` for content containers unless the PRD specifies mobile or a different breakpoint.
4. **No fake data that looks real.** Use plausible-looking placeholders, but never invent specific names, dates, or financial figures that could be mistaken for production data. Default avatars: solid `bg-slate-200` rounded squares.
5. **Always close every tag.** This is a static mock, not a snippet - invalid HTML is a Skill bug.
6. **Comment the brand anchor.** Top of `<body>`, one HTML comment: `<!-- Generated by knowject-prd-to-mock. Brand: <primary_color> + <font_family>. Voice: <voice>. -->`.

## Sectioning convention

Match the PRD structure 1:1. If the PRD lists five sections in an order, the HTML has five sections in that order. Use semantic tags (`<header>`, `<main>`, `<section>`, `<aside>`, `<footer>`) - `<div>` is the fallback only.
