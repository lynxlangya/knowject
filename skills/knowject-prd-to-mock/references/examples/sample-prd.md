# Mock 需求 — 项目知识中心首页

身份：产品经理 / PM

场景：在公司 wiki 之外另起一个"项目知识中心"页面，让团队成员一眼看到自己加入的项目的最新动态、知识沉淀进度、待办讨论。

页面结构（粗描）：

1. 顶栏：左侧 logo + 产品名，右侧用户头像。
2. 欢迎区：一句问候 + 今日待办数 + 本周新增知识数。
3. 项目卡片网格：每张卡显示项目名、最近活跃时间、知识条目数、3 个最近问答。
4. 侧边动态流：右侧固定一栏，时间倒序显示团队成员的最新提问 / 总结。
5. 底部 CTA：邀请同事 / 创建新项目两个按钮。

要求：

- 桌面端宽度。
- 不需要表单，纯展示。
- 文字风格沿用 brand.voice（professional, concise）。
