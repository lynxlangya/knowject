Claude Code + Codex Skill Pack

让项目知识，真正为团队所用。

Knowject 把 PRD、设计稿、API、项目文档和交接上下文变成可审阅的 AI 协作产物。它不是又一个泛用聊天入口，而是一组以真实项目上下文为锚点的 Skills。

查看仓库 安装指引
Capabilities

从项目事实出发，而不是从空白 prompt 出发。

Context Init

扫描项目栈、路径、品牌和 API 源，生成所有 Skill 共用的上下文锚点。

PRD to Mock

把需求文档转成品牌化单页 HTML mock，用于产品讨论和视觉对齐。

Read Design

把截图、PDF 或 Figma 导出拆成组件计划，再生成符合项目栈的骨架代码。

Read API

从 Express 或 OpenAPI 中发现 endpoint，并生成 typed client scaffold。

API to Types

把 OpenAPI 3 response schema 转成 TypeScript 类型，并接入生成客户端。

Memory Capture

把项目事实、决策和交接沉淀成 source-cited durable memory。

RAG Eval

生成带来源证据的 RAG 和引用质量评测用例，避免事实与 roadmap 混淆。

MCP Tool Designer

把 API surface 设计成 MCP tool candidates，标注风险、确认 gate 和回滚说明。

Guardrails

把 AI 产物做成可交付工程，而不是一次性回答。

Source cited

记忆、评测和工具设计都要求来源证据，降低 agent 幻觉和旧文档漂移。

Diff confirmed

写文件前先展示 diff，并要求用户确认，避免静默改动生产项目。

Secret safe

context、memory、eval 和 mock 都明确禁止复制 token、DB URL、base URL 等环境值。

Install

先安装 Skill pack，再让 agent 读真实项目。

git clone https://github.com/lynxlangya/knowject.git
cd knowject
bash skills/scripts/install.sh
安装后，在任意项目里运行 /knowject init，生成 knowject/context.yaml。之后 Claude Code 或 Codex 就可以按项目 的真实栈、路径和约束使用这些 Skills。
